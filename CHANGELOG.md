# Changelog

All notable public changes are documented here.

## 0.1.1 - 2026-08-11

- Translated the public Story Engine core documentation, rule cards, examples, Agent metadata, and behavioral-evaluation material into English.
- Kept `README.zh-CN.md` as the dedicated Simplified Chinese localization.
- Preserved all existing rule IDs and core semantics; no license or behavior-level rule change was introduced.
- Relaxed the validator's behavioral-suite version check so documentation-only patch releases do not require a behavioral-test corpus version bump.

## 0.1.0 - 2026-08-11

- Initial public release.
- Published eight plot-engine and risk-diagnosis rules.
- Added public input/output references, generic integration contract, JSON Schema, examples, deterministic validation, and model-behavior evaluation cases.
- Removed private development paths, private integration notes, internal provenance reports, and unverifiable test-pass claims from the public package.
